E-Commerce Web Application (MERN Stack)

Tech Stack:

Frontend: React, React Router DOM, Axios, @react-oauth/google, @stripe/react-stripe-js, Bootstrap

Backend: Node.js, Express.js, MongoDB (Mongoose), bcrypt, jsonwebtoken, dotenv, multer, nodemailer, joi, stripe, google-auth-library, cors

Description:
This project is a full-featured eCommerce web application built using the MERN stack (MongoDB, Express, React, Node.js) with secure authentication, seamless payments, and a modern responsive design. It provides a complete shopping experience, including user authentication, product management, cart handling, order placement, and payment processing.

Key Features:

🔐 Authentication & Authorization:
Implemented secure login and registration using JWT and bcrypt for password hashing, along with Google OAuth for quick social sign-in.

💳 Payment Integration:
Integrated Stripe API to enable safe and smooth online payments using @stripe/react-stripe-js on the frontend.

📦 Product Management:
Admins can add, update, and delete products with images using Multer for image uploads and MongoDB (Mongoose) for data storage.

✉️ Email Notifications:
Automated email verification and order confirmation emails using Nodemailer.

🧾 Form Validation:
Implemented server-side validation using Joi for robust and error-free user input handling.

🌐 CORS & Environment Management:
Configured CORS for secure API communication and dotenv for managing environment variables.

🎨 Modern Responsive UI:
Developed a clean, intuitive, and mobile-friendly interface using React and Bootstrap, ensuring smooth user navigation and visually appealing layouts.

🚀 API Structure:
Built modular and RESTful APIs in Express.js, ensuring scalability and maintainability.

Outcome:
A modern, responsive, and secure eCommerce platform that supports user-friendly shopping experiences, secure payments, and efficient product and order management. The project demonstrates expertise in full-stack web development, API integration, and end-to-end system design.
